# 🧠 Java Quiz Application

## 📌 Overview

This project is a **Quiz Application built using Java** that allows users to log in, read rules, attempt a quiz, and view their final score.

It demonstrates core Java concepts such as **OOP, event handling, and GUI **.

---

## ✨ Features

* 🔐 User login system
* 📜 Rules/instructions before starting the quiz
* ❓ Multiple-choice questions
* ⏱ Timer-based quiz
* 📊 Score calculation and result display

---

## 🧠 Application Flow

1. **Login (`login.java`)**

   * User enters name/details to start

2. **Rules (`rules.java`)**

   * Displays quiz instructions

3. **Quiz (`quiz.java`)**

   * Shows questions one by one
   * Handles answer selection
   * Tracks score

4. **Score (`score.java`)**

   * Displays final result after completion
